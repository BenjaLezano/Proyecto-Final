# PreviaZone 🍾🎉 - Proyecto Final Coderhouse

Plataforma web estática orientada a la organización y búsqueda de previas nocturnas en Buenos Aires y Argentina.

## 🚀 Sitio Desplegado
* **URL de Vercel / Netlify:** [https://previazone-arg.vercel.app](https://previazone-arg.vercel.app)

## 🛠️ Tecnologías y Características
* **HTML5 Semántico:** Estructura completa de 5 páginas con etiquetas SEO y atributos `alt` en imágenes.
* **SCSS Avanzado:** Arquitectura basada en partials (`@use`), variables, mixins con parámetros para media queries y uso de `@extend`.
* **Bootstrap 5.3.3:** Sistema de grillas responsive y Navbar interactiva estilada desde SCSS.
* **Animaciones:** `@keyframes` nativos para efectos de brillo neón y librería externa **AOS (Animate On Scroll)**.
* **Despliegue:** Publicado en producción con rutas relativas validadas.
